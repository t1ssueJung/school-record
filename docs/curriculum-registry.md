**GitHub Pages 버전:** 아래 원문 대조 결과와 611개 기준을 `src/domain.js`로 이관했습니다. GAS/Sheets의 자동 갱신 절차는 현재 버전에 적용되지 않습니다. 새 버전에서 출처가 달라진 근거는 다시 검토·생성해야 합니다.

  - `[6음02-05]`: 우리나라 음악 **국가유산**을 찾아 듣고 국악의 가치를 인식한다. PDF 순번 20.
- 공식 PDF 다운로드: [사회 별책7](https://ncic.re.kr/inv/org/download.do?year=2024&seq=10004260&orgType=org), [음악 별책12](https://ncic.re.kr/inv/org/download.do?year=2024&seq=10003999&orgType=org), [영어 별책14](https://ncic.re.kr/inv/org/download.do?year=2024&seq=10004085&orgType=org).
- 국어·도덕·수학·과학·체육은 NCIC PDF의 정규화한 본문에도 추출 원문이 존재하는지 자동 대조했다. 미술·실과·통합교과는 교육부 고시의 HWP 정의 문단을 사용했다. PDF에서 쪽을 확인한 기준은 PDF 순번, 나머지는 별책·학년군·정확한 코드 위치를 기록했다. HWP의 확인하지 않은 인쇄 쪽수는 만들지 않았다.
- 수학 `[6수01-10]`, `[6수01-14]`의 HWP 수식 개체는 PDF에서 직접 확인한 `÷`로 저장했다. 도덕 `[6도03-03]`은 원문에 끝 마침표가 없어 원문 그대로 등록했다.
- [국가교육위원회 2026-1호](https://www.ne.go.kr/new/user/bbs/BD_selectBbs.do?q_bbsDocNo=20260121102419070&q_bbsSn=1016)의 초등학교 적용은 부칙상 2028-03-01이다. 따라서 2026학년도 저학년 통합교과는 바른·슬기로운·즐거운 생활 세 교과로 취급한다.

각 레코드는 코드·원문·과목·학년군·고시 판본·공식 URL·원문 위치·확인일을 갖는다. 교사가 올린 문구는 공백/NFC 차이만 정규화하고 원문과 다르면 오류로 처리한다. 예를 들어 예전 ‘문화유산’ 문구는 경고를 피하려고 자동으로 ‘국가유산’으로 고치지 않는다. 학교자율시간 활동·특수교육 기본교육과정·재구조화 기준은 별도 원문 검토 없이 공식 기준으로 등록하지 않는다.

## 생성 원칙

611개 기준의 공통 기본 템플릿은 **업로드한 평가요소 + 명시된 수준**을 서술하는 보수적인 표현이다. 기준을 달성했다는 이유만으로 발표·협력·태도·성장·독립 수행 등의 관찰을 만들지 않는다. 파일에 서술형 평가결과가 있으면 교사가 실제 평가 근거임을 확인한 뒤 그 문장을 초안에 활용한다. 서술형 결과와 별도로 관찰메모를 보존하며, 임의로 관찰 사실로 재분류하지 않는다. 단계만으로 풍부한 행동 서술을 생성하는 엔진은 아니다.

원문 검증과 평가결과의 사실 검증은 다르다. 결과 문장은 반드시 교사가 사실관계·수준과의 일치·기재 허용 여부를 다시 확인해야 한다.

## 데이터 이관과 갱신

원래 레지스트리는 HWP5 BodyText의 PARA_TEXT 레코드와 `pdftotext -layout`으로 추출한 PDF를 대조해 만들었다. 현재는 원문 정의·공식 URL·판본·원문 위치를 `src/domain.js`에 포함했다. 원문 문서 전체는 이 프로젝트에 복제하지 않았다.

기존 GAS 저장소를 이 버전이 자동으로 읽거나 공유하지 않는다. 이 버전의 백업 형식은 암호화된 schema 3이며, 원본 엑셀을 다시 불러오거나 이 버전에서 만든 백업으로 복원해야 한다. 새 공식 판본을 반영할 때는 업로드 원문과 대조를 유지하고 과거 출처와 일치하지 않는 평어를 재검토해야 한다. 현재 학년도는 2026으로 고정되어 있다.
