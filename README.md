# 교과 평어 작성 지원 · GitHub Pages

**Google Apps Script 없이 GitHub Pages에서 실행하는 버전입니다.** GitHub Actions가 테스트·빌드·배포하고, 명렬표와 평가 엑셀 분석부터 학생별 평어 작성·승인·CSV 내보내기까지 브라우저에서 처리합니다. Google 로그인, Apps Script ID, Drive 권한, API 키, 별도 서버 설정이 없습니다.

## GitHub에 올려 실행하기

저장소 최상위의 `index.html`은 빌드가 끝난 실제 배포 파일입니다. `assets/`와 `samples/`를 함께 올려야 합니다. 원본 개발 HTML은 `app.html`에 별도로 보관합니다.

1. 압축을 풀고 파일을 저장소 최상위에 올립니다. `index.html`, `assets/`, `samples/`가 같은 위치에 있어야 합니다.
2. 저장소 **Settings → Pages → Source: Deploy from a branch**에서 **main / (root)**를 선택합니다.
3. Pages 배포가 끝나면 `https://계정.github.io/저장소이름/` 주소로 접속합니다. 처음에는 ‘새 교사 저장소’를 만듭니다.

이 방식은 Node 설치·Secret·별도 서버·Google 설정 없이 배포됩니다. GitHub 무료 계정의 Pages는 공개 저장소에서 사용할 수 있습니다. 학생 자료·CSV·암호화 백업은 GitHub에 올리지 마세요.

소스를 수정하는 개발자는 `app.html`과 `src/`를 수정하고 **`npm run release`를 실행한 뒤 갱신된 `index.html`, `assets/`, `samples/`도 함께 커밋**합니다. 직접 배포한 `index.html`을 개발 원본으로 덮어쓰지 마세요.

선택적으로 `.github/workflows/pages.yml`을 사용하는 경우 Source를 **GitHub Actions**로 선택하면 Actions에서 테스트·빌드한 `dist/`를 배포할 수도 있습니다. 현재 게시 방식이 브랜치 배포라면 변경할 필요가 없습니다.

## 사용 순서

1. 앱에서 교사 저장소 이름과 12~128자 비밀번호를 직접 설정합니다. 미리 정해진 관리자 비밀번호는 없습니다.
2. 학급을 설정하고 명렬표 XLSX를 불러옵니다. 컬럼 매핑·중복·누락·교체 내역을 확인하고 저장합니다.
3. 과목을 선택하고 평가 XLSX를 불러옵니다. 반복 머리글·병합된 학생 칸이 있는 인쇄형도 자동 인식합니다.
4. 영역·성취기준·평가요소·단계·서술형 결과를 검토합니다. 빈 단계는 추정하거나 아래 영역으로 복사하지 않습니다. 제외되는 행과 서술형 결과는 교사가 확인해야 합니다.
5. 선택 교과의 평어 초안을 생성하고, 근거를 펼쳐 확인·수정·승인합니다. 다른 교과의 자료와 승인은 유지합니다.
6. 승인한 평어를 UTF-8 BOM CSV로 내려받습니다. 설정에서 **암호화 백업 받기**도 사용하세요.

1~2·3~4·5~6학년군의 공식 성취기준 **611개**를 지원합니다. 상·중·하와 매우 잘함·잘함·보통·노력 요함을 구분하고, 다른 척도는 교사가 대응을 명시합니다. 저학년 바른·슬기로운·즐거운 생활은 세 교과 근거를 종합합니다. 미등록 코드·원문 불일치·학생 불일치·부적절 표현은 오류로 표시합니다.

가명 샘플은 앱 설정 화면과 `public/samples/`에서 받을 수 있습니다. `인쇄형-국어-가명.xlsx`가 첨부 예시와 같은 구조의 샘플입니다. 1학년·6학년 자료도 제공합니다.

## 저장과 ‘로그인’ 방식

이 버전은 **기기별 암호화 저장소**를 엽니다. Google/GitHub 계정으로 교사를 인증하는 서버나 학교 조직 허용 목록이 없습니다. 웹페이지는 Pages 설정에 따라 누구나 열 수 있으나, 이미 저장한 학생 자료를 읽으려면 해당 기기와 저장소 비밀번호가 필요합니다.

- 학생·평가·평어·승인 자료는 PBKDF2-SHA256 600,000회로 도출한 키와 AES-256-GCM으로 암호화해 IndexedDB에 저장합니다. 비밀번호와 평문 학생 자료를 저장하지 않습니다. 저장소 이름·수정 시각은 목록 표시용으로 공개 메타데이터이며, 이름에는 학생 개인정보를 적지 마세요.
- 엑셀·평어를 GitHub나 외부 AI에 업로드하지 않습니다. 앱 코드·스타일·가명 샘플만 GitHub에서 내려받습니다.
- 30분 뒤 또는 ‘저장소 잠그기’를 누르면 화면 자료와 메모리의 키를 비웁니다. 공유 PC에서는 사용 후 잠그세요.
- 브라우저·기기마다 저장소가 다릅니다. 자료는 자동 동기화되지 않습니다. 다른 기기로 옮길 때는 암호화 백업 JSON을 내려받아 비밀번호로 복원합니다. 복원은 기존 저장소를 덮어쓰지 않고 별도 저장소를 만듭니다.
- 비밀번호를 잊으면 복구할 수 없습니다. 브라우저 데이터 삭제·사생활 보호 창 종료·저장 공간 정리로 자료가 사라질 수 있습니다. 암호화 백업을 학교의 보관 정책에 따라 관리하세요. CSV는 암호화되지 않은 다운로드입니다.
- 여러 창에서 동시에 바꾼 자료는 저장 리비전을 비교해 덮어쓰기를 차단합니다. 다시 잠갔다 열어 최신 자료를 확인하세요.
- 로컬 승인 기록은 교사의 검토 표시이며, 서버 신원 확인·전자서명·학교의 공식 결재가 아닙니다. 나이스 자동 확정·제출이나 CSV 직접 업로드 호환성을 제공하지 않습니다.

기관의 실제 학생 자료 처리·기기 보안 정책에 맞는 환경에서 사용하세요. 이 전환은 GitHub만 사용하는 실행 구조를 위해 이루어졌으며, 이전 GAS의 교사 Google 계정 접근 통제와 공유 Sheets 저장은 포함하지 않습니다.

## 로컬 개발과 검증

Node.js 22.12 이상:

```sh
npm ci --ignore-scripts
npm test
npm run build
npx playwright install chromium
npm run test:ui
npm run dev
```

시스템 Chromium을 쓴다면 `CHROMIUM_PATH=/usr/bin/chromium npm run test:ui`로 실행할 수 있습니다. `npm run test:ui`는 빌드된 `dist/`를 GitHub Pages 프로젝트 하위 경로에 해당하는 테스트 출처로 제공해 실제 브라우저의 암호화·IndexedDB·XLSX 읽기·사용자 흐름을 검사합니다. 사업 로직이나 저장소를 모의 API로 대체하지 않습니다.

개발 화면은 개발 서버의 `/app.html`에서 엽니다. `base: './'` 설정으로 사용자 사이트, 저장소 하위 경로, 사용자 지정 도메인에서 상대경로 자산을 사용합니다. `file://`로 HTML만 여는 실행은 지원하지 않습니다. HTTPS로 호스팅하세요. GitHub Pages가 HTTPS 주소를 제공합니다.

## 구성과 한도

- `src/domain.js`: 공식 기준·검증·평어 문장 규칙
- `src/excel.js`: 브라우저 XLSX 파싱 및 수식/외부 연결/크기 검사
- `src/engine.js`: 명렬표·과목별 평가·생성·승인·CSV 처리
- `src/vault.js`: 암호화·IndexedDB·백업/복원·비밀번호 변경·저장 충돌 처리
- `src/main.js`, `src/style.css`: 화면
- `.github/workflows/pages.yml`: 테스트 후 GitHub Pages 배포

값 전용 한 시트의 XLSX, 최대 2MB·40열, 표형 500자료행·인쇄형 원본 2000자료행을 지원합니다. ZIP 내부는 100파일·해제 후 10MB 제한으로 검사합니다. 수식·외부 연결·매크로·임베디드 개체는 거부합니다. 저장소별 평가·평어 각 5,000건, 문장 2,000자와 저장 평문 합계 8MB는 앱의 구현 한도이며 교육부의 법정 글자 수 제한이라고 해석하지 않습니다. 현재 검증 학년도는 2026입니다.

평가요소와 수준만 있는 경우 해당 평가의 성취수준을 보수적으로 서술합니다. 수업에서 관찰하지 않은 태도·발표·협력·향상 정도를 만들어내지 않습니다. 서술형 평가결과는 교사가 실제 근거임을 확인한 뒤 초안에 활용하고, 모든 결과는 교사가 수정·승인해야 합니다.

공식 근거는 [2026 기재요령 검증](docs/compliance-2026.md), [성취기준 판본·범위](docs/curriculum-registry.md)를 확인하세요. [검증 결과와 아키텍처 변경](docs/verification.md)도 함께 제공합니다.

공식 호스팅 설명: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).
